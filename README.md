PORTOFOLIO ZAIM — UPDATE PROJECT & CONTACT

STRUKTUR FOLDER
- index.html
- style.css
- script.js
- img/foto-saya.png
- img/project-1.jpg
- img/project-2.jpg
- img/project-3.jpg
- img/project-4.jpg

SECTION MY PROJECTS
1. Simpan screenshot/foto project ke folder img.
2. Beri nama project-1.jpg, project-2.jpg, project-3.jpg, atau project-4.jpg.
3. Jika memakai nama lain, ubah atribut src pada tag <img class="project-image"> di index.html.
4. Ubah judul, kategori, dan deskripsi singkat di bagian project-info.
5. Ubah data-title, data-category, dan data-description pada article yang sama. Data ini muncul saat kartu project diklik.

SECTION CONTACT
Form memiliki kolom nama, email, nomor telepon, subject, dan pesan.
Saat SEND MESSAGE ditekan, website membuka aplikasi email dengan isi pesan yang sudah disusun.
PENTING: buka script.js dan ganti:
const recipient = 'emailkamu@gmail.com';
dengan alamat email aktif milikmu.
Form mailto tidak mengirim otomatis; pengunjung tetap harus menekan Send/Kirim di aplikasi email. Agar terkirim langsung dari website, dibutuhkan backend atau layanan form endpoint.

MENJALANKAN WEBSITE
1. Buka folder PORTOFOLIO ZAIM di VS Code.
2. Jalankan index.html dengan Live Server.
3. Pastikan foto project berada di folder img.

Teknologi: HTML, CSS, JavaScript.
